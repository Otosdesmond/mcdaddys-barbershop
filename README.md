# McDaddy's Premium Barbershop

Static website for McDaddy's Premium Barbershop in Cranbourne West, Victoria.

## Deploy on Vercel

1. Open Vercel.
2. Import the GitHub repository.
3. Select the default project settings.
4. Deploy.

No build command or framework is required. The site is a static `index.html`.

## Source note

The supplied HTML was used as the content basis for this repository. The original file contained large inline base64 image payloads, so the repository version uses external image URLs for a much smaller, Vercel-friendly repository.
